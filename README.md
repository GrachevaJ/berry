# Ягода — адаптивный интернет-магазин фермерских ягод

Кроссбраузерный адаптивный интернет-магазин (главная страница и страница оформления заказа) с поддержкой мобильной, планшетной и десктопной версий.

---

## 🛠 Технологический стек

* **Разметка и стили:** HTML5, CSS3, Sass (SCSS), методология БЭМ
* **Сетки и адаптивность:** Flexbox, CSS Grid, фиксированная адаптивная сетка
* **Скрипты и API:** JavaScript (ES6+), Яндекс/Google Maps API
* **Графика и сборка:** Gulp, Retina (`2x`), WebP, SVG-спрайты, Stylelint

---

## ✨ Реализованный функционал

* **Адаптивная вёрстка по БЭМ:** Реализована вёрстка главной страницы и страницы заказа под 3 брейкпоинта с центрированием контентной области и тянущимися на всю ширину фонами.
* **Мобильное меню (Progressive Enhancement):** Навигация реализована в двух режимах — интерактивное открытие/закрытие по кнопке «гамбургер»/«крестик» на **JavaScript** и открытое меню при отключённом JS.
* **Формы и интерактивная карта:** На странице заказа настроены семантические поля ввода (`tel`, `email`) с проработкой всех состояний элементов (hover, active, focus, error). Интегрирована интерактивная карта с кастомным маркером.
* **Оптимизация ассетов и сборка (Gulp):** Настроена автоматическая компиляция Sass, автопрефиксер, минификация файлов, генерация `WebP` и `SVG`-спрайтов.
